# Glosarium Istilah

## Fm 01
- Monev 1 = Form 01 = FORM-01
- Monev pembelajaran semester berjalan.

## Kaprodi
- Kaprodi = Ketua Program Studi.
- Kaprodi adalah penanggung jawab program studi pada level prodi.

## Submit
- Submit = mengirim final = status SUBMITTED.
- Draft = status DRAFT = belum final.

## Belum submit
- "Belum submit" berarti belum ada submission dengan status SUBMITTED.
- Jika hanya DRAFT, maka masih dianggap belum submit.
